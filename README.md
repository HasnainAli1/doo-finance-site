# doo.FINANCE website

Homepage for doo.FINANCE — Odoo Gold Partner for accounting and finance.

Static site: `index.html` plus `assets/`. No build step and no framework; it opens directly in a browser and runs on GitHub Pages.

## Publish with GitHub Pages

Settings → Pages → Source: **Deploy from a branch** → Branch: `main`, folder `/ (root)` → Save.
The site appears at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

## Before going live

Replace the sample content: the numbers dashboard, the migration estimator formula, client logos and the testimonial wording.

The Odoo website itself is built with the `website_doo_finance` Odoo module, not this file.
